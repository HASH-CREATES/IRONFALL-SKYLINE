# IRONFALL // SKYLINE

Original browser-based 3D armored-superhero flight game — Grade 12 science
exhibition project. Fly the IRONFALL MK-1 armor across a procedural 8-district
metro: high-speed flight, boost, hover, dive, rooftop landings, repulsor
combat against the Null Syndicate, five missions + free flight, full helmet
HUD, and **webcam hand-gesture control with keyboard fallback** (same flight
physics either way).

Assets: gameplay visuals are 100% original (every model, material, effect and
sound is generated by this project's own code at runtime). The landing-page
showroom figure is a 3D model supplied by the project owner — provenance in
`docs/ASSET_MANIFEST.md`.

## Run (development)

```bash
npm install
npm run dev        # http://localhost:5173
```

## Run (exhibition / production)

```bash
npm run build      # emits dist/
npm run preview    # serves dist/ on http://localhost:8000
```

or on the venue laptop with no Node installed: copy `dist/`, then run
`run.bat` inside it (uses Python's http.server) and open
<http://localhost:8000>.

## Armory (Character Screen)

The landing page has an **ARMORY** — pick between 4 original suit frames
(MK-1 Extremis / Aegis Vanguard / Wraith Nyx / Solstice Gladiator). Each frame
has its own paint scheme, dossier lore and **real gameplay modifiers** (speed,
armor, energy, weapon output). The hero re-skins instantly on select; EQUIP
commits the frame (persisted). Flown frame shows in-flight: heavier frames
genuinely have more integrity, interceptors boost faster and are frailer.

## Controls

| Input | Action |
|---|---|
| **Space** | take off / thrust up |
| **W / S** | accelerate / brake-thrust |
| **A / D** | strafe |
| **Arrow keys / mouse** | pitch & turn — click canvas for pointer lock, or hold right-button and drag to steer |
| **Q / E** | roll |
| **Shift** | boost |
| **X** | air brake |
| **C / Ctrl** | descend |
| **Left click** | repulsor fire |
| **F** | unibeam |
| **G / R** | EMP burst |
| **Tab** | cycle target |
| **Z** | auto-level |
| **Esc** | pause |
| **T** | exhibition tech panel |

Gesture mode (optional): click ENABLE HAND CONTROL on the landing page →
allow camera → follow the short calibration. Gestures drive the same flight
model; if the camera is unavailable the game stays on keyboard automatically.

## Tech

TypeScript + Vite 5 + Three.js 0.160 (WebGL2), custom flight dynamics (no
physics engine), MediaPipe Tasks Vision 0.10.14 HandLandmarker **vendored
locally** (`public/mediapipe`, `public/assets/models`) so the exhibition runs
fully offline, procedural WebAudio (no audio files).

Full documentation in `docs/` (architecture, QA report, asset manifest,
gesture decision, known issues, development log).
