## ■ The Pitch

| | |
|:--|:--|
| **The city** | A Manhattan-shaped procedural island — Hudson & East Rivers, Central Park, landmark spires, a suspension bridge, yellow cabs, patrol blimps, and 2,200+ city blocks. |
| **The suit** | High-speed flight, boost, hover, superman dive, rooftop landings, repulsor blasts, unibeam and EMP — custom flight dynamics, no physics engine. |
| **The enemies** | The Null Syndicate: interceptors, hunters, gunships, shield orbiters, AA walkers — sleek crimson-lensed machines that lead their shots. |
| **The modes** | 5 missions + Free Flight + a full **Armory** character screen with 4 gameplay-modifying suit frames. |
| **The control** | Keyboard/mouse **or** webcam hand tracking (MediaPipe, fully vendored — runs 100% offline). Same flight physics either way. |

---

## ■ Quick Start

```bash
npm install
npm run dev        # → http://localhost:5173
```

**Production build**

```bash
npm run build      # emits dist/
npm run preview    # → http://localhost:8000
```

> **Exhibition machine (no Node)?** Copy `dist/` over, double-click `run.bat`,
> open <http://localhost:8000>. Fully offline.

## ■ Controls

| Input | Action | Input | Action |
|:--|:--|:--|:--|
| <kbd>Space</kbd> | Take off / thrust up | <kbd>Shift</kbd> | Boost |
| <kbd>W</kbd><kbd>S</kbd> | Accelerate / brake | <kbd>X</kbd> | Air brake |
| <kbd>A</kbd><kbd>D</kbd> | Strafe | <kbd>C</kbd> | Descend |
| <kbd>←</kbd><kbd>→</kbd> / mouse | Pitch & turn | <kbd>Q</kbd><kbd>E</kbd> | Roll |
| Click | Repulsor fire | <kbd>F</kbd> | Unibeam |
| <kbd>G</kbd> / <kbd>R</kbd> | EMP burst | <kbd>Tab</kbd> | Cycle target |
| <kbd>Z</kbd> | Auto-level | <kbd>Esc</kbd> | Pause |

**Gesture mode:** click *ENABLE HAND CONTROL* on the landing page → allow camera →
follow the short calibration. Camera denied? The game stays on keyboard automatically.

## ■ Armory — 4 Suit Frames

| Frame | Role | Gameplay modifiers |
|:--|:--|:--|
| **MK-1 EXTREMIS** | All-round baseline | Balanced speed, armor, energy |
| **AEGIS VANGUARD** | Siege bulwark | 133 integrity, slower accel |
| **WRAITH NYX** | Interceptor prototype | 210 top speed, only 78 integrity |
| **SOLSTICE GLADIATOR** | Exhibition gunship | 1.45× weapon output, slower cooldowns |

Frames re-skin the hero instantly, persist across reloads, and **genuinely change how you fly**.

## ■ Tech

| Layer | Choice |
|:--|:--|
| Language | TypeScript 5.3 (strict) |
| Rendering | Three.js 0.160 · WebGL2 · MSAA HDR composer · filmic grade · VSM sun shadows |
| Flight | Custom dynamics — takeoff/hover/boost/dive/landing state machine |
| Gestures | MediaPipe Tasks Vision HandLandmarker, WASM + model **vendored locally** |
| Audio | Procedural WebAudio — zero audio files |
| Build | Vite 5 · ~966 kB bundle (268 kB gzip) |

Full documentation lives in [`docs/`](docs/) — architecture, QA report, asset manifest,
gesture technical decision, known issues, development log.
